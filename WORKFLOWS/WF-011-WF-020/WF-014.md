# WF-014: Skill Opportunity Scoring

## Workflow Spec
Rank candidate skills against user goals and evidence.

## Workflow ID
`WF-014`

## Workflow Name
Skill Opportunity Scoring

## Purpose
Rank candidate skills against user goals and evidence.

## Trigger
Inputs and demand signals are available.

## Inputs
- Goal fit, demand, transferability, effort, and evidence.

## Outputs
- Transparent weighted score with assumptions.

## Dependencies
- AGENT-002 Skill ROI Agent
- Evidence quality and confidence rules
- User goals and constraints

## Process Flow
1. Validate the decision context and identify missing evidence.
2. Separate observed facts, estimates, and assumptions.
3. Apply the relevant scoring or prioritization method.
4. Recommend a small validation step before irreversible investment.
5. Record confidence, decision owner, and next review date.

## Expected Results
A transparent, reviewable decision artifact that supports the user's stated goal without promising a guaranteed outcome.

## Marketplace Potential
Reusable as a module in Skill ROI Agent and as a component of creator growth, career planning, and capability-building bundles.

## Future Versions
- Add industry benchmarks and calibrated outcome data.
- Add portfolio and marketplace performance integrations.

## Notes
- Status: Defined
- Recommendations must include assumptions and confidence.
