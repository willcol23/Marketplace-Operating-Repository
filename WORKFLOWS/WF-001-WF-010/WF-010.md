# WF-010: Daily Command-Center Digest

## Workflow Spec
Provide a daily operational view of the inbox.

## Workflow ID
`WF-010`

## Workflow Name
Daily Command-Center Digest

## Purpose
Provide a daily operational view of the inbox.

## Trigger
Configured daily digest time is reached.

## Inputs
- Priority queue, commitments, follow-ups, meetings, failures.

## Outputs
- Digest with highlights, deadlines, approvals, and metrics.

## Dependencies
- AGENT-001 Email Command Agent
- User approval and permission policy
- Relevant email provider integration

## Process Flow
1. Validate the request and available context.
2. Apply the user policy and identify any approval gate.
3. Produce a source-linked proposal.
4. Surface ambiguity or exceptions before taking external action.
5. Record the result and audit metadata.

## Expected Results
The user starts the day with an actionable email plan.

## Marketplace Potential
Reusable as a module in the Email Command Agent product and in freelancer,
agency, and creator operations bundles.

## Future Versions
- Add configurable provider adapters and team-level policies.
- Add quality metrics and reusable industry presets.

## Notes
- Status: Defined
- External actions require explicit approval unless narrowly configured by the user.
