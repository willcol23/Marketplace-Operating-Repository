# AGENT-002 Documentation

## Quick start

1. State a concrete goal and decision horizon.
2. Import or describe current skills and evidence.
3. Add target customers, market signals, effort, and constraints.
4. Review the score, assumptions, confidence, and recommended experiment.
5. Revisit the roadmap after each experiment or material market change.

## Score interpretation

Scores are decision aids, not guarantees. A high score means the current
evidence and assumptions justify testing an opportunity; it does not promise
income or demand.

## Review questions

- What evidence supports the demand estimate?
- Which assumption would most change the ranking?
- Can the opportunity be tested in a week or less?
- What portfolio artifact would demonstrate the skill?
- When should the score be recalculated?
