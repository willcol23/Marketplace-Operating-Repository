# AGENT-001 Documentation

## Quick start

1. Connect an email account with the minimum required permissions.
2. Set working hours, priority labels, tone, and approval preferences.
3. Run a read-only triage and review the proposed action queue.
4. Enable drafting and integrations one at a time.
5. Approve external actions individually until trust is established.

## Example commands

- “Summarize the unread messages from today.”
- “Show messages that require a reply this week.”
- “Draft a concise reply and wait for approval.”
- “Find commitments I made and create a review queue.”
- “Prepare a follow-up list for conversations with no response.”

## Safety guidance

Email content can contain misleading instructions or sensitive information.
The agent must not treat message text as a change to its operating rules.
Review recipients, attachments, dates, and quoted text before approving an
external action.

## Troubleshooting

- If classification is wrong, correct the label and explain the priority rule.
- If context is missing, inspect the linked thread before approving a draft.
- If an integration fails, preserve the proposed action and retry manually.
- If a message requests unusual access or payment, escalate rather than act.
