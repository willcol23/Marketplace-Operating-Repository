# AGENT-001 Release Plan

## Release objective

Publish a dependable first version that handles common email operations while
making every external action visible and reviewable.

## Milestones

| Milestone | Deliverable | Exit criteria |
| --- | --- | --- |
| Specification | Agent rules and workflow definitions | All ten workflows reviewed |
| Prototype | Local sample inbox demonstration | Happy path and exception path complete |
| Validation | Safety and usability review | Approval gates and audit trail verified |
| Packaging | Listing, screenshots, demo, and guide | Marketplace checklist complete |
| Launch | Initial marketplace release | Support channel and feedback log active |

## Launch checklist

- [ ] Confirm email provider permissions are least-privilege
- [ ] Test no-send, no-delete, and no-forward defaults
- [ ] Validate each workflow with representative sample messages
- [ ] Publish setup and troubleshooting documentation
- [ ] Record version, changelog, and known limitations
- [ ] Define support response and rollback procedures

## Post-launch review

Review adoption, correction rate, draft acceptance, approval compliance, and
support requests after the first release cycle.
